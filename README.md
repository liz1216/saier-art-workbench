# 赛尔美术工作台

独立的单头美术调试页面，默认采用反转图灵单头模型与黑底剧场灯光。

支持替换 GLB、皮肤和眼睛贴图，调整灯光、材质与相机，导入导出参数，保存截图，以及通过 H 隐藏和恢复界面。

使用 HTTP 静态服务打开本目录，例如 `python3 -m http.server 8904 --bind 127.0.0.1`。GitHub Pages 直接发布仓库根目录。

默认模型采用反转图灵单头的 mouthfix 版本，以及灰白皮肤。网页贴图上限为 2048 像素，几何、表情变形和其他非图像数据与源模型一致。发布文件使用标准 gzip 压缩，页面读取后由浏览器解压。

本地替换的素材需与导出的参数 JSON 一起交回。刷新页面后默认恢复内置素材。
